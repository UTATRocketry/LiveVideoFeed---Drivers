# Live Video Feed Compression Board — STM32 Driver Code

## Overview
This repository contains the embedded firmware and driver code for a **live video feed compression board** developed using STM32 microcontrollers and built with **STM32CubeIDE**.

The firmware enables real-time acquisition, processing, and compression of video data through hardware peripherals and optimized memory transfers. The project is designed for embedded systems requiring efficient live video streaming and compression capabilities.

## Hardware
- ADV7180WBCP32Z
- STM32H742VGT6
- RunCam Split 4-25
